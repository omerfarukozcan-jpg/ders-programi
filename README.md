# 📚 DersPlan

Modern, hızlı ve kullanımı kolay **haftalık ders programı web uygulaması**.

Ders sayını belirle, programını oluştur, derslerini ekle ve programını tek bir yerde yönet. Açık/koyu tema desteği sayesinde istediğin görünümü kullanabilirsin.

## ✨ Özellikler

* 📅 Haftalık ders programı
* 🔢 Siteye ilk girişte günlük ders sayısı seçimi
* ⚙️ Sonradan ders sayısını değiştirme
* ➕ Ders ekleme
* 🗑️ Ders silme
* 👨‍🏫 Öğretmen / sınıf bilgisi ekleme
* 🕐 Otomatik ders saatleri
* ☀️ Açık tema
* 🌙 Koyu tema
* 💾 Programın tarayıcıda otomatik kaydedilmesi
* 📱 Mobil uyumlu tasarım
* ✨ Modern ve sade arayüz
* 🚀 Harici kütüphane veya sunucu gerektirmez

## 🕐 Ders Saatleri

Uygulama şu okul düzenine göre ders saatlerini otomatik hesaplar:

* Okul başlangıcı: **08:30**
* Ders süresi: **40 dakika**
* İlk 4 teneffüs: **10 dakika**
* 5. teneffüs: **50 dakika**
* 5. teneffüsten sonraki teneffüsler: **5 dakika**

Ders sayısını değiştirdiğinde saatler otomatik olarak yeniden hesaplanır.

## 🚀 Kullanım

Projeyi bilgisayarında çalıştırmak için:

1. Projeyi indir.
2. `index.html` dosyasını tarayıcıda aç.
3. İlk açılışta günde kaç ders olduğunu seç.
4. **Programı Oluştur** butonuna bas.
5. **Ders Ekle** ile derslerini programa ekle.

Program bilgileri tarayıcının `localStorage` özelliğinde saklanır.

## 🌐 GitHub Pages ile Yayınlama

Projeyi internette yayınlamak için GitHub Pages kullanılabilir.

1. GitHub'da yeni bir repository oluştur.
2. Repository'yi **Public** yap.
3. `index.html` dosyasını repository'ye yükle.
4. **Settings → Pages** bölümüne gir.
5. Source olarak **Deploy from a branch** seç.
6. Branch olarak `main`, klasör olarak `/ (root)` seç.
7. **Save** butonuna bas.

GitHub Pages etkinleştirildikten sonra uygulama internet üzerinden erişilebilir hale gelir.
